# Aureate

A type collection built on stated proportion. Every family shares one x-height (898 units on a
2048 em) and takes its other measures from it by powers of the golden ratio φ, or, in the Solar
families, by whole-number ratios and the roots √2, √3 and √6. Each release states its relations as
numbers and measures them in the finished fonts.

| Package | Fonts | What it is |
| --- | --- | --- |
| [AureateCollection_1.701](AureateCollection_1.701) | 52 | Seven Romans (Living, Condensed, Tall, Short, Olympian, Variable, Monumental) and six Sans (Sans, Condensed, Tall, Short, Geometric, Variable), four styles each |
| [AureateRomanTitling_1.820](AureateRomanTitling_1.820) | 4 | Titling Roman with wedge serifs, and a small-capitals family; Regular and Bold |
| [AureateDestiny_1.901](AureateDestiny_1.901) | 4 | Light, wide-set titling sans in two lattices: Aureate Destiny (golden) and Aureate Destiny Solar (Apollonian); Regular and Bold |
| [AureateDestinySerif_1.910](AureateDestinySerif_1.910) | 4 | Light titling capitals with serifs on the five Platonic solids: Aureate Destiny Serif and Aureate Destiny Solar Serif; Regular and Bold. 498 relations certified |

Each package holds `fonts/` (TTF and WOFF2), a README with its system and its limits, `specimen/`,
`verification/` and the `source/` scripts that built it.

## Install

Download a package's `fonts/` folder and install the TTF files (macOS: Font Book; Windows: right-click,
Install). The WOFF2 files are for the web.

The Romans derive from Liberation Serif (Google, Red Hat) and the Sans from Source Sans 3 (Adobe),
both under the SIL Open Font License 1.1. Their copyright notices are kept in `OFL.txt` and in every
font file. Aureate Type, 2026.
